# پک فوتبال خیابانی

مدل‌های low-poly دست‌ساز برای فوتبال توی کوچه. همه جدا اینجاست تا شخصی‌سازی راحت باشد — هیچ فایلی بیرون این پوشه به این پک وابسته نیست.

## محتوا

**وسایل (`props/`)** — هر مدل یک `.obj` + یک `.mtl` هم‌نام:

| فایل | چیست |
| --- | --- |
| `goal_small` | دروازهٔ کوچک فلزی (۱٫۶ × ۱٫۱ متر) |
| `cone` | مخروط ترافیکی (۲۵ سانت) |
| `tire_stack` | سه لاستیک روی هم |
| `brick_stack` | تودهٔ آجر (دو تا کنار هم = دروازهٔ آجری) |
| `bench` | نیمکت چوبی (۱٫۴ متر) |

**بچه‌ها (`kids/`)** — قد ≈ ۱٫۱ متر، رو به `+Z`:

| فایل | کیست |
| --- | --- |
| `kid_ali` | کاپیتان: کلاه قرمز، پیراهن راه‌راه قرمز/سفید، شلوارک آبی |
| `kid_reza` | پابرهنه با پیراهن سبز و شلوارک خاکی |
| `kid_hassan` | قدبلند: پیراهن زرد و شلوار تیرهٔ بلند |

## شخصی‌سازی

- **رنگ:** عددهای `Kd` را در `.mtl` عوض کن (قرمز/سبز/آبی، ۰ تا ۱). نام متریال‌ها را بدون هماهنگ‌کردن `.obj` عوض نکن.
- **شکل و اندازه:** همه با `Tools/make_street_models.py` ساخته می‌شوند — عددها را عوض کن و دوباره اجرا کن.
- **چیدمان:** دنیای نمونه `Worlds/street_kids.kimia` را ببین.

## نکته

- بچه‌ها مجسمه‌اند (اسکلت ندارند)، پس کلیپ‌های `assets/animations` رویشان نمی‌نشیند.
- پیشوندهای محفوظ موتور (`Goal`، `Ball`، `Player`، `Wall_`، `Block_`) را به‌کار نبر — دروازهٔ اینجا `MiniGoal` نام دارد.
