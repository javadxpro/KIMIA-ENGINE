# منطق بصری، رابط کاربری و انتشار

بازی‌سازی بدون کدنویسی: قاعده‌ها، HUD، ورودی، ذرات، Blueprint/صحنه و انتشار.

---

## منطق بصری

یک بازی مجموعه‌ای از **قاعده**‌هاست:

```text
WHEN <چیزی رخ می‌دهد>   IF <این درست است>   DO <این کارها>
```

فهرست از بالا به پایین اجرا می‌شود؛ وقتی دو قاعده مخالف‌اند، بالایی برنده است.

- **رویدادها**: `start`، `every-frame`، `key`/`key-held`، `collision`، `area-enter`/`area-exit`، `timer`، `variable`، `event`. `area-enter` یک‌بار شلیک می‌کند؛ برخورد دوطرفه است؛ تایمر آهنگ خودش را نگه می‌دارد.
- **کنش‌ها**: `set`/`add`، `move`/`move-to`/`rotate`، `spawn`/`destroy`، `sound`/`animate`/`message`، `raise`، `wait`، `end-game`. رویدادِ بلندشده در همان فریم به قاعده‌های بعدی می‌رسد.
- **متغیرها**: نوشتن روی متغیر نبوده آن را می‌سازد؛ خواندنِ حذف‌شده صفر می‌دهد.

مثال کامل بدون یک خط کد:

```text
WHEN start                      DO set score 0
WHEN key space                  DO add score 1   DO sound kick
WHEN every-frame  IF score >= 3 DO message "YOU WIN"  DO end-game
```

`LogicRuntime` می‌گوید *چه* باید بشود؛ دنیا انجامش می‌دهد — پس منطق بدون رندر/پنجره/فیزیک تست می‌شود.

## رابط کاربری بازی (HUD)

چهار پنل: `label` (متن)، `bar` (نوار)، `box` (قاب)، `button` (دکمه با رویداد).

- متن زنده با آکولاد: `SCORE {score}` — متغیر نبوده جایش خالی می‌ماند.
- مکان با کسر (۰…۱)، نه پیکسل — روی هر اندازهٔ صفحه درست است.
- هر پنل `visible` دارد (مثلاً صفحهٔ پیروزی فقط در پایان).

## ورودی — یک کار، چند دستگاه

یک **کنترل** (`Control`) یک کنش است با چند راه فعال‌سازی: `key` (کیبورد)، `pad` (دسته)، `on-screen` (دکمهٔ گرد روی صفحه)، `clip` (کلیپ FBX)، `sound`. دکمه‌ها گردند چون انگشت گرد است. کنترل خودش رویداد هم هست: `WHEN event jump DO …`.

## ذرات

یک **افکت** یک دستور غذاست (`count/life/speed/spread/gravity/size/shrink` + رنگ اول/آخر). کنش `effect` آن را پخش می‌کند:

```text
WHEN collision Ball + Wall    DO effect explosion on Ball
```

جاذبه و مقاومت هوا مال هر ذره است؛ طول عمر تصادفی (۷۰–۱۳۰٪)؛ پراکندگی قطعی (مولد داخلی، نه `<random>`).

## Blueprint و صحنه

- **Blueprint**: جسمِ یک‌بار تنظیم‌شده را با **Keep** ذخیره کن و با کلیک در صحنه بکوب؛ همهٔ اجزا (فیزیک، برچسب، صدا، بافت، استخوان) همراهش می‌آیند.
- **Stage**: هر صحنه دنیای خودش را دارد؛ صحنهٔ جاری پاک نمی‌شود؛ کنش `scene` بازیکن را واقعاً جابه‌جا می‌کند.

## انتشار

دکمهٔ **Publish** یک پوشه می‌سازد: `game.kimia` (کل بازی) + `play.sh` + `README.txt`. بازیِ منتشرشده **ویرایشگر ندارد**: مستقیم وارد بازی می‌شود، `/bench` ۴۰۴ است، API ویرایش جواب نمی‌دهد، دکمهٔ «منو» حذف می‌شود.

```bash
bash play.sh          # پورت 8080
bash play.sh 9000     # پورت دیگر
```
