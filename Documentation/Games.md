# بازی‌ها و پروفایل‌ها

یک موتور، چند بازی. همهٔ قابلیت‌ها در موتورند؛ هر بازی فقط یک **پروفایل** است.

---

## پروفایل‌های داخلی

| پروفایل | `name` | زمین (X×Z) | محیط | توپ | بازیکن | امتیاز |
| --- | --- | --- | --- | --- | --- | --- |
| گلف کیمیا | `golf` | ۱۰×۲۴ | چمن | دقیق | `mode shot`، بدون پرش | سوراخ |
| فوتبال خیابانی: کوی ابوذر | `street` | ۱۶×۵ | آسفالت | فانتزی | سرعت ۵، پرش ۱٫۸ | گل |
| زمین چمن: کوی ابوذر | `grass` | ۴۰×۲۵ | چمن | دقیق | سرعت ۴، پرش ۰٫۶ | گل |
| بتل گراند | `battleground` | ۴۰×۴۰ | شنی | دقیق | سرعت ۴٫۵، پرش ۱٫۰ | آرنا |
| زمین آزاد | `sandbox` | ۲۰×۲۰ | چمن | دقیق + سؤال | سرعت ۴، پرش ۱٫۲ | — |

فایل‌های داخل `Profiles/` هنگام بیلد کنار باینری کپی می‌شوند؛ ویرایش آن‌ها بازی را عوض می‌کند — بدون C++.

## فرمت پروفایل

```text
# KIMIA profile v1
name street
title فوتبال خیابانی ایران: کوی ابوذر
field 16.000000 5.000000
environment asphalt
player speed 5.000000 jump 1.800000
ball fantasy choice off
kick 3.000000 0.600000 2.000000
```

| خط | معنی |
| --- | --- |
| `name <id>` | شناسهٔ بازی (توکن ASCII) |
| `title <متن>` | برچسب منو |
| `field <طول Z> <عرض X>` | اندازهٔ زمین (۴…۸۰) |
| `environment grass\|sand\|night\|asphalt` | محیط پیش‌فرض |
| `player speed <v> jump <h>` | سرعت و ارتفاع پرش (۰ = بدون پرش) |
| `ball accurate\|fantasy choice on\|off` | توپ پیش‌فرض و پرسیدن سؤال هنگام افزودن |
| `kick <پایه> <ضریب سرعت> <پاپ>` | فرمول شوت (در `mode shot`: پایه + قدرت×ضریب) |
| `mode kick\|shot` | دونده (فوتبال) یا نشانه‌گیری/شارژ (گلف) |
| `scoring gate\|hole` | خط دروازه یا سوراخ |
| `wind <شتاب> <جهت>` | باد روی توپِ در حرکت |
| `team <نفر>` / `match <ثانیه>` | ترکیب تیم و ساعت مسابقه |
| `weather <باران> <خیسی>` | آب‌وهوا |
| `time <ساعت>` | ساعت شروع (شب/روز) |
| `tricks on\|off` | حرکات نمایشی |
| `ai <مهارت>` | زیرکی بازیکن‌های کامپیوتری (۰ = مجسمه) |
| `camera orbit\|chase\|broadcast` | سبک دوربین |
| `rules on\|off` | اوت/آفساید/خطا |
| `stamina <نرخ>` | سرعت خستگی (۰ = هرگز) |
| `arena on\|off` | حالت تیرانداز سوم‌شخص |

## گیم‌پلی

- **گلف** (`mode shot`): نشانه ← →، «شوت» را نگه دار (قدرت ۰→۱ چرخه‌ای)، رها کن. سوراخ‌ها به ترتیب `Hole_1..N`؛ فقط سوراخ نوبت توپ را می‌گیرد؛ جدول ضربه با par؛ صفحهٔ «پایان دور». باد شوت را خم می‌کند؛ بهترین دور در فایل دنیا ذخیره می‌شود.
- **فوتبال** (`mode kick`): بدو و شوت کن؛ در خیابانی حرکات نمایشی (لایی/رولت/روپایی) امتیاز می‌گیرند؛ در چمن قوانین (اوت/آفساید/خطا) و استقامت فعال‌اند.
- **آرنا** (`arena on`): شلیک `raycast` است نه گلولهٔ شبیه‌سازی‌شده. سلاح از پروفایل می‌آید (`weapon <جان> <خشاب> <نرخ> <آسیب> <برد> <پرکردن>`). نرخ شلیک، آتش خودی بی‌آسیب، پر شدن خودکار خشاب خالی، respawn افتاده‌ها و پوشش ۹ بلوکی، بازی را قابل اجرا می‌کنند.

## کنترل‌ها

| ورودی | عمل |
| --- | --- |
| WASD / فلش‌ها | حرکت (Shift = گام ریز در سازنده) |
| Space | پرش (شارژ/شوت در گلف) |
| ← → | نشانه‌گیری گلف |
| F | شلیک (آرنا) |
| R | پر کردن خشاب (آرنا) / توپ از نو |
| درگ | چرخش دوربین |
| لمس (APK) | جوی‌استیک حرکت، دکمهٔ عمل، درگ دوربین، پینچ زوم |

روی APK کنترل‌های روی صفحه با بیت‌مپ‌فونت خود موتور کشیده می‌شوند (MOVE / SHOT|JUMP|FIRE / RELOAD).
