# ویرایشگر (KIMIA World)

ویرایشگر گزینه‌محور، رابط کاربری (KIMIA Editor) و ویوپورت لمسی.

---

## ویرایشگر گزینه‌محور

همه‌چیز با دکمه و پرسش فارسی انجام می‌شود: دنیای جدید → **کدام بازی؟** → افزودن جسم (بازیکن، توپ، بلوک، دیوار، دروازه، جعبه، مدل از فایل، سوراخ) → مدیریت اجسام → محیط → **PLAY**.

- PLAY واقعی: بازیکن شوت می‌زند، توپ با فیزیک می‌غلتد، گل/کاپ شمرده می‌شود، جعبه‌ها هل داده می‌شوند.
- دوربین مداری: چرخش حول مرکز صحنه (یا جسم انتخاب‌شده)، زوم و بازنشانی.
- فهرست سلسله‌مراتبی + بازرس با ویرایش دقیق (گام ۰٫۱) و رنگ/حذف/جابه‌جایی آزاد.
- ذخیره/بارگذاری کامل در فرمت SceneIO-v1؛ فایل‌های قدیمی `.kimia` هم بار می‌شوند.

## KIMIA Editor (Workbench)

نشانی: `http://127.0.0.1:8080/bench`. چیدمان و اصطلاح‌ها از Unity آمده‌اند، ولی کدش از صفر برای این موتور نوشته شده.

| پنل | نقش |
| --- | --- |
| **Hierarchy** | فهرست همهٔ موجودیت‌ها (چپ) |
| **Inspector** | توصیف و ویرایش جسم انتخاب‌شده (وسط) |
| **Game** | نمای زندهٔ بازی (راست) |
| **Toolbar** | ابزارها، Play/Pause/Step، اسنپ، ساخت جسم (بالا) |
| **Project** | فایل‌ها، پریفب‌ها، صحنه‌ها (پایین) |
| **Console** | کارهایی که ویرایشگر همین‌الان کرد (پایین) |

ابزارها: Select / Move (درگ روی زمین) / Rotate / Scale؛ کلیدهای Q/W/E/R همان‌اند. Play مستقیم وارد بازی می‌شود، Pause فقط شبیه‌سازی را فریز می‌کند، Step یک فریم جلو می‌رود. Hierarchy از Duplicate/Delete پشتیبانی می‌کند؛ Project از List/Scan، Rename، Delete و Upload.

معماری: صفحه هیچ‌چیز از موتور نمی‌داند — سرور درخواست را به لایهٔ `studio` می‌دهد، آن از `WorldEditor` سؤال واقعی می‌پرسد و JSON برمی‌گرداند؛ پس هر تصمیم در موتور (تست‌پذیر) می‌ماند.

## ویوپورت لمسی (Picking)

روی تصویر بزن و بکش؛ عدد تایپ نکن.

- **انتخاب با لمس**: نزدیک‌ترین جسم به دوربین برنده است؛ زمین انتخاب نمی‌شود؛ جسم‌های نازک جعبهٔ حداقلی می‌گیرند.
- **کشیدن**: جسم روی صفحهٔ افقی هم‌ارتفاع خودش می‌لغزد؛ شروع نیاز به جابه‌جایی کوچک دارد؛ چسبیدن به شبکه فقط X/Z را می‌گیرد؛ کشیدن به سمت افق رد می‌شود.
- **معماری**: `Engine/World/Picking` هندسهٔ خالص است (دوربین + جعبه‌ها → ضربه)؛ برنامه دوربین را هر فریم می‌دهد، تصمیم در موتور گرفته می‌شود.

## API برنامه‌نویسی (روی `WorldEditor`)

- ساخت: `createObject(kind, at)` — `cube/sphere/plane/block/wall/goal/crate/hole/player/ball`.
- `duplicateEntity`، `renameEntity` (نام‌های `Player/Ball/Ground` محفوظ‌اند)، `rotateEntity`، `scaleEntity`، `setEntityRotation`.
- کنترل پخش: `enterPlayMode()`، `setPaused()`، `stepOnce()`.
- انیمیشن: `animationClips(name)`، `playClip`، `posedMesh(name, out)` — کلیپ‌ها از اسکلت خودِ FBX.
- فیزیک چرخش را نمی‌بیند: برخورددهنده‌ها محور-همراستا می‌مانند (چرخشِ نمایشی، فیزیکِ جعبه‌ای — محدودیت مستند).
