# رندر

مسیرهای رندر KIMIA و خط لولهٔ رنگ مشترک میان آن‌ها.

---

## مسیرها

| مسیر | کجا | وضعیت |
| --- | --- | --- |
| GL 3.3 Core | دسکتاپ (dlopen + EGL) | اصلی |
| GLES 3.0 | اندروید (EGL window surface) | اصلی APK |
| WebGL2 | مرورگر (Emscripten) | اصلی وب |
| D3D11 | Windows PC | اصلی PC |
| رسترایزر نرم‌افزاری | همه‌جا | **تضمینی** (fallback همیشگی) |

همهٔ مسیرها یک `RenderScene` می‌گیرند و یک تصویر می‌دهند؛ خط لولهٔ رنگ (زیر) بیت‌به‌بیت یکسان است.

## مدل نوری

- **PBR Cook-Torrance**: roughness/metallic هر جسم، با Fresnel شلیک برای دی‌الکتریک و فلز.
- **نور جهت‌دار** (key light) + سقف **۸ نور نقطه‌ای** (`PointLight`: مکان، رنگ، شعاع افت).
- **سایه**: shadow map با PCF در GL/GLES3/WebGL2.
- **تون‌مپ فیلمی + sRGB** دقیق: GL و نرم‌افزاری همان ریاضی را اجرا می‌کنند، پس فریم در هر مسیر یکسان است.
- مه و فاصلهٔ محو.

## ساختار

| فایل | نقش |
| --- | --- |
| `Renderer` | حالت GL؛ `initialize/render/captureImage/shutdown` |
| `renderSoftware` | رسترایزر CPU: z-buffer، درون‌یابی پرسپکتیو-صحیح، برش مثلث در برابر near، سایه‌زنی Lambert |
| `GLFunctions` | لودر توابع GL بدون هدر؛ روی اندروید `dlopen("libGLESv3.so")` |
| `EGLContext` | کانتکست: `create` (pbuffer) و `createWindow` (سطح پنجرهٔ اندروید) + `swapBuffers` |
| `Shaders` | یک بدنهٔ شیدر، `#version 330 core` روی دسکتاپ و `#version 300 es` روی Emscripten/اندروید |

## فونت بیت‌مپ و HUD

`kimia::font` (در `Engine/Graphics/BitmapFont.h`) فونت ۵×۷ داخلی برای ASCII ۳۲…۱۲۶ است — بدون فایل فونت. ابزارها: `textWidth`، `drawText`، `fillRect` (پس‌زمینهٔ نیمه‌شفاف)، `drawBar` (نوار قدرت/جان).

HUD روی خودِ فریم کشیده می‌شود (پیش از کدگذاری/ارسال)، پس GL و نرم‌افزاری و APK یکسان دیده می‌شوند.

---

## نرم‌افزاری — مسیر تضمینی

رسترایزر CPU همیشه کامپایل و همیشه در دسترس است: بدون GPU، بدون درایور، روی Termux/PS4/سروِر. ویژگی‌ها:

- z-buffer با عمق پرسپکتیو-صحیح (`clipZ/clipW` جداگانه درون‌یابی می‌شوند)
- حذف سطح پشتی با نرمال جهان
- برش مثلث در برابر صفحهٔ near (Sutherland–Hodgman) — زمینِ بزرگ که دوربین داخلش است درست رسم می‌شود
- سقف تصویر ۸۱۹۲²
